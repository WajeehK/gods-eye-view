# Gods Eye View

Interactive 3D globe of world affairs: country leaders, economy, alliances, partners/adversaries, trade, foreign bases, nuclear range and tracked conflict hotspots.

Static site (GitHub Pages). Data: Wikidata (leaders), World Bank (economy), mledoze/countries, world-atlas; curated layer in data/world.js. Rebuild data with `python3 tools/build_data.py`.
